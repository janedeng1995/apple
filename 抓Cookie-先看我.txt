苹果抢购助手 - 抓 PC 微信 Cookie
====================================

最简单的用法
------------
1. 保持分享包文件夹完整，不要只把本文件复制出去。
2. 先打开 PC 微信，登录你要抓 Cookie 的账号。
3. 在 PC 微信里打开苹果小程序，进入一次购物袋页面。
4. 进入分享包的“工具”文件夹，双击：
   一键抓Cookie.cmd
5. 如果 Windows 弹出“用户账户控制”，点“是”。
6. 等待黑窗口自动运行，不要关闭微信。
7. 看到“✓ 已存 身份-PC-xxxx.txt”就表示成功。
8. 抓到的文件在分享包根目录的“身份”文件夹里。

成功后怎么用
------------
1. 打开分享包根目录的 AppleMonitorPro.exe。
2. 在“抢购任务”里点“选择身份文件”。
3. 选择“身份”文件夹里刚生成的 身份-PC-xxxx.txt。
4. 选择要抢的型号，勾选“启用”。
5. 一个身份文件只能用于一个任务。

常见错误
--------
1. 没找到 Weixin.exe / WeChatAppEx.exe
   → PC 微信没有打开，或者没有登录。打开微信后重试。

2. 内存里没有 cookieJar
   → 微信虽然打开了，但没有在 PC 微信里打开苹果小程序。
   → 打开苹果小程序，进入购物袋页面后再抓。

3. HTTP 403
   → 请回到 PC 微信，再打开一次苹果小程序购物袋页面，然后重试。

4. HTTP 541
   → Apple 临时风控。等 5 到 15 分钟再抓，不要连续猛按。

5. 提示没有管理员权限
   → 不要直接双击 py 文件。
   → 必须双击“一键抓Cookie.cmd”，并在 UAC 提示中点“是”。

6. 提示没有 Python
   → 正常分享包应自带 抓Cookie-PC.exe。
   → 如果 exe 丢失，再让豆包按“给豆包-抓Cookie教程.md”指导安装 Python。

安全提醒
--------
1. 身份文件等同账号登录凭据。
2. 不要把“身份”文件夹里的 txt 发给任何人。
3. 不要把 Cookie、User-Agent、身份指纹截图发给豆包或其他 AI。
4. 排错时只说错误文字，不要粘贴完整身份文件。
