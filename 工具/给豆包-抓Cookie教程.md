# 给豆包看的抓 Cookie 教程

你正在帮助一个不会编程的 Windows 用户，从 **PC 微信** 里提取苹果小程序 Cookie，供 `AppleMonitorPro` 抢购助手使用。请按本文一步步指导，不要要求用户把完整 Cookie、身份文件原文或账号凭据发给你。

## 一、这是什么

分享包里有抓 Cookie 工具：

```text
工具/
├─ 一键抓Cookie.cmd        用户需要双击的文件
├─ 抓Cookie-PC.exe         自带运行环境的主程序
├─ 抓身份-PC.py            Python 源码版本
├─ wx_cookie.py            源码依赖文件
├─ 抓Cookie-先看我.txt      普通用户说明
└─ 给豆包-抓Cookie教程.md   本文
```

抓取结果会自动保存到分享包根目录：

```text
身份/
└─ 身份-PC-xxxxxxxx.txt
```

这个文件就是 `AppleMonitorPro` 的“身份文件”。

## 二、开始前必须满足

1. 电脑系统是 Windows 10 或 Windows 11。
2. PC 微信已经安装并登录。
3. 要用哪个微信账号抢购，就登录哪个微信账号。
4. 在 PC 微信里打开苹果小程序，并进入一次购物袋页面。
5. PC 微信在整个抓取过程中不能关闭。
6. 用户必须双击分享包内的 `工具\一键抓Cookie.cmd`，建议允许管理员权限。

## 三、标准操作步骤

请让用户严格按下面顺序操作：

1. 解压完整分享包。
2. 打开 PC 微信并登录目标账号。
3. 在 PC 微信中打开苹果小程序。
4. 进入购物袋页面，确认页面能正常显示。
5. 不要关闭微信，回到分享包文件夹。
6. 打开 `工具` 文件夹。
7. 双击 `一键抓Cookie.cmd`。
8. Windows 弹出“用户账户控制”时点“是”。
9. 等待黑色窗口输出。

窗口中通常会出现：

```text
① 找 PC 微信进程…
② 把内存里的号分开认…
③ 号 #1 ...
④ 线上验证（PC 微信 UA 请求 /chat/bag）…
   → HTTP 200
   ✓ 活的：这份 cookie + PC 档 UA 通
✓ 已存 身份-PC-xxxxxxxx.txt
```

看到 `HTTP 200` 和 `✓ 已存 身份-PC-xxxxxxxx.txt` 才算成功。

## 四、成功后怎么配置

1. 打开分享包根目录的 `AppleMonitorPro.exe`。
2. 进入“抢购任务”页面。
3. 选择刚生成的 `身份-PC-xxxxxxxx.txt`。
4. 选择要抢的具体型号。
5. 勾选启用。
6. 一个身份文件只能配一个任务。
7. 多个微信账号要分别登录、分别抓取，每个账号生成一个身份文件。

## 五、常见错误和回答

### 1. “没找到 Weixin.exe / WeChatAppEx.exe”

原因：PC 微信没打开，或者微信主程序名不符合预期。

指导用户：

1. 确认微信已经登录。
2. 确认任务管理器里能看到微信进程。
3. 重新双击 `一键抓Cookie.cmd`。

### 2. “内存里没有 cookieJar”

原因：没有在 PC 微信内真正打开苹果小程序。

指导用户：

1. 打开 PC 微信。
2. 搜索或找到苹果小程序。
3. 进入首页后再进入购物袋。
4. 保持微信开启，重新抓取。

### 3. HTTP 403

原因：小程序页面没有加载完整，或者 Cookie 不是当前有效页面生成的。

指导用户：

1. 回到 PC 微信。
2. 打开苹果小程序。
3. 再进入一次购物袋页面。
4. 重新执行抓取。

### 4. HTTP 541

原因：Apple 临时风控或限流。

指导用户：

1. 停止连续重试。
2. 等 5 到 15 分钟。
3. 再抓一次。
4. 不要频繁运行。

### 5. 提示没有 curl_cffi

优先让用户使用分享包自带的 `抓Cookie-PC.exe`。

如果 exe 不存在，按下面方式安装：

1. 安装 Python 3.10 以上版本。
2. 安装时勾选 `Add python.exe to PATH`。
3. 打开 `工具` 文件夹。
4. 再次双击 `一键抓Cookie.cmd`。
5. 脚本会自动执行：

```powershell
python -m pip install -U curl_cffi
```

### 6. 程序一闪而过

不要直接运行 `.py`。

必须双击：

```text
工具\一键抓Cookie.cmd
```

### 7. 抓到了多个文件

这是正常的。不同微信账号会生成不同身份文件。每个文件对应一个账号，配置时不要混用。

## 六、安全规则

给豆包的硬性要求：

1. 不让用户发送完整 Cookie。
2. 不要求用户发送身份文件原文。
3. 不显示完整手机号、邮箱、证件信息。
4. 不把身份文件上传到任何网站。
5. 抓取完成后，提醒用户不要把 `身份` 文件夹发给别人。
6. 如果用户要排错，只让用户发送错误文字、HTTP 状态码或已脱敏截图。

## 七、可直接复制给豆包的指令

```text
请阅读我发给你的《给豆包-抓Cookie教程.md》，然后一步一步教我抓 Cookie。

我的情况是：Windows 电脑，已经安装 PC 微信。
请你不要让我把完整 Cookie 发给你，也不要让我上传身份文件。
每一步只告诉我当前应该点哪里、双击哪个文件、看到什么算成功。

如果我说报错，请先问我是哪一行错误，再根据教程给我对应处理方法。
最后请提醒我把生成的 身份-PC-xxxx.txt 放到 AppleMonitorPro 的“抢购任务”里使用。
```
